# Hyperbaric Chamber

Strona internetowa dla gabinetu terapii hiperbarycznej. Projekt został wykonany z wykorzystaniem **React** oraz własnego backendu w **Node.js**, umożliwiającego zarządzanie opiniami klientów zapisanymi w bazie danych MySQL.

## 🌐 Live

https://hyperbaric-chamber.onrender.com

## 🚀 Technologie

- React
- JavaScript
- Node.js
- Express.js
- MySQL
- HTML5
- CSS3
- Git / GitHub

## ✨ Funkcjonalności

- responsywna strona internetowa,
- prezentacja usług i informacji o terapii hiperbarycznej,
- formularz kontaktowy,
- system opinii klientów oparty o MySQL,
- REST API do pobierania i dodawania opinii,
- komunikacja frontend ↔ backend.

## ⚙️ Uruchomienie projektu

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
cd server
npm install
npm start
```
